# 🚀 portfolio-site

Статический веб-сайт для демонстрации автоматического развёртывания (CI/CD) с помощью GitHub Actions.

## Статус сборки
![Deploy static site](https://github.com/hhhakkki/portfolio-site/actions/workflows/deploy.yml/badge.svg)

## Описание
Этот проект автоматически публикуется на GitHub Pages при каждом push в ветку `main`. 
Настроен workflow-файл `.github/workflows/deploy.yml`.
